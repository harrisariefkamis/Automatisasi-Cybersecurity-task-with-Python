# Automatisasi-Cybersecurity-task-with-Python
Mempelajari bahasa pemrograman Python dan bagaimana Python dapat digunakan secara efektif untuk mengotomatiskan tugas-tugas terkait keamanan. Mengurangi upaya manual dan manusia dalam melakukan tugas-tugas umum dan berulang.


### Ringkasan Materi

1. **Basics of Programming (Dasar-dasar Pemrograman)**
* Mempelajari pengantar mengapa pemrograman, khususnya menggunakan Python, menjadi keterampilan esensial dan alat yang sangat membantu bagi seorang analis keamanan siber untuk mengotomatiskan tugas.


2. **Data Types (Tipe Data)**
* Memahami berbagai jenis tipe data dasar di Python yang digunakan untuk menyimpan informasi, seperti **string** (teks), **integer** (angka bulat), **float** (angka desimal), **Boolean** (nilai True/False), dan **list** (kumpulan data).


3. **Variables (Variabel)**
* Belajar cara menggunakan variabel sebagai "wadah" untuk menyimpan data, serta bagaimana cara menetapkan (*assign*) dan memperbarui nilai variabel di dalam program.


4. **Conditional Statement (Pernyataan Kondisional)**
* Mempelajari cara membuat keputusan dalam kode menggunakan pernyataan logika (seperti `if`, `elif`, dan `else`) agar program dapat menjalankan blok kode tertentu hanya ketika kondisi tertentu terpenuhi.


5. **Iterative Statement (Pernyataan Iteratif / Loop)**
* Memahami cara mengotomatiskan tugas berulang menggunakan struktur *loop*, yang terbagi menjadi dua jenis utama:
* **`for` loop:** Digunakan untuk mengulangi blok kode sebanyak jumlah yang telah ditentukan.
* **`while` loop:** Digunakan untuk mengulang blok kode selama suatu kondisi tertentu bernilai benar.
